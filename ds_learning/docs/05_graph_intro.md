# Phase 5：图（Graph）— 存储与遍历

---

## 🔗 桥梁：什么是图

图就是**事物之间的关系网**。生活中的图无处不在：

| 场景 | 顶点（Vertex） | 边（Edge） |
|------|------|------|
| 微信好友 | 每个人 | 互相关注 = 一条边 |
| 地铁线路 | 每个站 | 两站之间通车 = 一条边 |
| 网页链接 | 每个网页 | 一个链接 = 一条有向边 |
| 课程依赖 | 每门课 | 先修关系 = 一条有向边 |

**你已经在用的图**：朋友圈的六度人脉、导航的最短路线、微博的热搜传播——全是图。

## 分类：四种基本类型

```
无向图              有向图              加权图
1——2               1 → 2              1 —5→ 2
|   |  朋友关系     ↓   ↓  关注关系     |     |  路长5km
3——4               3 ← 4              3 —2→ 4
```

| 类型 | 特点 | 例子 |
|------|------|------|
| 无向图 | 双向通行 | 朋友关系、桥梁 |
| 有向图 | 单向通行 | 微博关注、课程依赖 |
| 加权图 | 边上有数字 | 地图距离、机票价格 |
| 连通图 | 任意两点可达 | 一个朋友圈 |

## 两种存储方式

### 邻接矩阵 `int[][]`

```java
//    0 1 2 3 4
// 0 [0 1 0 1 0]   0 连着 1 和 3
// 1 [1 0 1 0 1]   1 连着 0,2,4
// 2 [0 1 0 0 0]
// 3 [1 0 0 0 1]
// 4 [0 1 0 1 0]

// 查 0 和 1 是否相连：matrix[0][1] == 1  → O(1) 秒查 ✅
// 但 5 个顶点要 25 个格子 → O(V²) 空间 💀
```

**适合稠密图（边多的），不适合社交网络那种上亿节点的稀疏图。**

### 邻接表 `List<Integer>[]` ⭐ 最常用

```java
adj[0] = [1, 3]        // 顶点0的邻居
adj[1] = [0, 2, 4]     // 顶点1的邻居
adj[2] = [1]           // 顶点2的邻居
adj[3] = [0, 4]
adj[4] = [1, 3]

// 空间 O(V+E)，省内存
// 查邻居 O(degree)，够快
```

**实际开发 99% 用邻接表。** 你的 Demo 代码也是用邻接表建的。

## DFS 深度优先 — 一条路走到黑

**口诀：看过就标记，然后逐个扎进没去过的邻居。**

```java
void dfs(int v, boolean[] visited) {
    visited[v] = true;               // ① 标记
    print(v);                        // ② 做事

    for (int neighbor : adj[v]) {    // ③ 逐个邻居
        if (!visited[neighbor])      // ④ 没去过？
            dfs(neighbor, visited);  // ⑤ 扎进去！
    }
}
```

**追踪 DFS(0)：**
```
0 → 1(第一个邻居) → 2(1的第一个) → 2没未去邻居，回溯
                → 4(1的第二个)   → 3(4的第一个) → 回溯到0
                → 3(0的第二个，已去过，跳过)

路线: 0 → 1 → 2 → 4 → 3
```

**关键是回溯**：一条路走到底（走到 2），没路了就往回退到上一个岔路口（退到 1，再去 4）。

## BFS 宽度优先 — 一层一层往外扩

**口诀：用队列！队头出列做事，邻居排队等。**

```java
void bfs(int start) {
    Queue<Integer> q = new LinkedList<>();
    q.offer(start);                   // ① 起点入队
    visited[start] = true;

    while (!q.isEmpty()) {
        int v = q.poll();             // ② 队头出列
        print(v);                     // ③ 做事

        for (int neighbor : adj[v]) { // ④ 逐个邻居
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                q.offer(neighbor);    // ⑤ 入队排队
            }
        }
    }
}
```

**追踪 BFS(0)：**
```
初始: 队=[0]
出0 → 邻居[1,3]入队 → 队=[1,3]
出1 → 邻居[2,4]入队 → 队=[3,2,4]
出3 → 邻居全去过 → 队=[2,4]
出2 → 邻居全去过 → 队=[4]
出4 → 邻居全去过 → 队空，结束

路线: 0 → 1 → 3 → 2 → 4
```

## DFS vs BFS 一眼对比

```
      0            DFS: 0→1→2→4→3    一条路到底
     / \           BFS: 0→1→3→2→4    先近的再远的
    1   3
   / \  |
  2   4─┘
```

| | DFS | BFS |
|------|------|------|
| 核心结构 | 栈（递归调用栈） | 队列（`Queue`） |
| 走法 | 一条路走到黑 | 一层一层扩散 |
| 什么时候用 | 找所有路径、回溯问题 | 最短路径（无权图）、层序遍历 |
| 跟你学过的 | Phase 1 递归 | Phase 3 队列 |

## 🧠 核心两句话

1. **存储**：邻接表 = `List<Integer>[]`，每个顶点存它的邻居列表，O(V+E) 空间。
2. **遍历**：DFS 用递归扎到底，BFS 用队列层层扩。两者都能遍历全图，路径不同。
