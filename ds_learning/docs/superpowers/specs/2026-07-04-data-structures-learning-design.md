# 数据结构学习方案设计

**日期**：2026-07-04
**目标**：为大学《数据结构》课程做系统预习
**背景**：已完成 Java OOP 五个阶段学习（first_java），有 C/Python 基础

---

## 1. 学习目标

- 系统掌握数据结构课程核心知识
- 理解每种数据结构的逻辑结构、存储结构、基本操作
- 会用大O记号分析时间/空间复杂度
- 用 Java 独立实现课程要求的各类数据结构
- 为下学期课程建立扎实基础

## 2. 整体路线（7个阶段，约9-10周）

```
Phase 1: 复杂度分析 + 泛型 + 递归     ≈ 1周
Phase 2: 线性表（顺序表 + 链表）       ≈ 1.5周
Phase 3: 栈与队列                      ≈ 1周
Phase 4: 树（二叉树/BST/堆/Huffman）   ≈ 2周
Phase 5: 图（存储/遍历/最短路径）      ≈ 1.5周
Phase 6: 查找与排序                    ≈ 1.5周
Phase 7: 综合实战项目                  ≈ 1周
```

## 3. 每次交互模式

沿用 first_java 验证过的五步法：

| 步骤 | 内容 |
|------|------|
| 🔗 桥梁 | 从生活例子引出今天的问题 |
| 👀 Demo | 可运行的代码演示 |
| 📖 讲解 | 核心概念讲解，随时提问 |
| ✍️ 练习 | 自己动手写代码，Claude review |
| 🧠 小结 | 一句话记住核心 |

## 5. 设计原则

- **从生活出发**：每个结构先问"解决什么问题"
- **画图理解**：指针、树、图能用图说清就不用文字
- **写了才算会**：每个阶段都有动手练习
- **对比学习**：相似结构对比选型
- **阶段小结**：记录到 LEARN_LOG.md，方便复习
