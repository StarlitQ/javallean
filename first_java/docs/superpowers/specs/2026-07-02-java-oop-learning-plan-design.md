# Java OOP 学习方案设计

**日期**：2026-07-02
**目标**：为下学期《面向对象程序设计-Java》课程做准备
**背景**：有 C 和 Python 基础，但有所遗忘；对 OOP 概念不熟悉

---

## 1. 学习目标

- 理解面向对象编程的核心思想（封装、继承、多态、抽象）
- 掌握 Java 基本语法和常用类库
- 能在控制台下独立完成一个简单的小项目
- 为下学期课程建立知识基础，开学后轻松跟上

## 2. 整体路线

采用**对比迁移 + 实战驱动**的路线，利用 C/Python 已有知识作为桥梁。

### 路线图

```
第零阶段（1周）  →  用 Java 复习基础语法，找回编程手感
第一阶段（1周）  →  理解"什么是类，什么是对象"，写出第一个类
第二阶段（1.5周）→  继续学 Java 语法（和 C 不同的地方重点讲）
第三阶段（2周）  →  封装 + 继承（OOP 的核心）
第四阶段（2周）  →  多态 + 接口（OOP 最抽象也最关键的部分）
第五阶段（1.5周）→  做一个综合小项目，模拟真实场景
```

## 3. 每次交互的模式

每个学习单元约 1 小时，结构固定为五步：

| 步骤 | 时间 | 内容 |
|------|------|------|
| 🔗 桥梁 | 5min | 用简单例子引出今天要学的问题 |
| 👀 Demo | 10min | 在当前工程里看到可运行的 Java 代码 |
| 📖 讲解 | 20min | Claude 讲解核心概念，用户随时提问 |
| ✍️ 练习 | 20min | 用户在 VS Code 里写代码，Claude review |
| 🧠 小结 | 5min | 一句话记住今天的核心 |

## 4. 项目结构

在当前 `first_java` 项目中按阶段组织代码：

```
src/
├── phase00_warmup/       ← 第零阶段：热身复健
├── phase01_intro/        ← 第一阶段：OOP 入门
├── phase02_syntax/       ← 第二阶段：Java 语法
├── phase03_encapsulation/← 第三阶段：封装与继承
├── phase04_polymorphism/ ← 第四阶段：多态与接口
└── phase05_project/      ← 第五阶段：综合项目
```

此外项目根目录下维护一个 `LEARNING_LOG.md` 记录进度。

## 5. 设计原则

- **只看下一步**：不一次性展示所有细节，每次只关注当前单元
- **对比优先**：每个新概念都从 C/Python 的已知概念引入
- **代码即笔记**：练习代码保存详细注释，构成完整的复习资料
- **允许遗忘**：第零阶段专门用于复健，后续也会随时复习此前内容
